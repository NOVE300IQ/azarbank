# AzarBank

Yo guys 👋

this time I was learning HTML, CSS and Javascript, so I decided to make a fake bank because apparently making a calculator wasn't enough 😭.

AzarBank is just a fictional digital banking website. I started it while following some tutorials, then slowly changed stuff, fixed my broken CSS, added animations and made the buttons actually do something.

![AzarBank](/screenshot.png)

You can check the Home, About Us, Contact, blog and careers pages. The Request Invite button also works now, so congratulations, you can officially pretend to join a bank that doesn't exist 💀.

## How to run it?

Clone the repo,<br>
open it in your code editor and open `index.html`.<br>
That's literally it. You can also use Live Server if you want.

I used ChatGPT mainly when I got stuck with debugging and some HTML, CSS and Javascript problems. I still went through the code, changed things around and tested everything myself.

this is just a learning project, so please don't try depositing your life savings here (seriosuly)
